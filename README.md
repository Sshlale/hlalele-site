# HlaleleDAO

## Overview

HlaleleDAO is a governance platform designed to encode sovereignty and create governance systems for African founders and stewards. We blend intelligence, onboarding, and compliance into ceremonial protocols that honor our heritage while building sustainable systems for the future.

## Mission

To create decentralized governance structures that:
- Empower African founders and communities
- Preserve and honor our cultural heritage
- Integrate compliance with ceremonial wisdom
- Build systems that stand the test of time

## Key Features

- **Governance Protocols**: Ceremonial frameworks for decision-making and compliance
- **Archive Scrolls**: Living testimony and immutable records of our collective journey
- **Intelligence Integration**: Blending traditional wisdom with modern approaches
- **Community Onboarding**: Structured processes for welcoming new participants

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/Sshlale/hlalele-site.git
   cd hlalele-site
   ```

2. Open `index.html` in your browser to view the site locally

3. Deploy to GitHub Pages or Vercel for production hosting

## Deployment

### GitHub Pages
1. Go to repository Settings → Pages
2. Select `main` branch as source
3. Site will be available at `https://sshlale.github.io/hlalele-site`

### Vercel
1. Connect your GitHub repository to Vercel
2. Deploy automatically on push to main
